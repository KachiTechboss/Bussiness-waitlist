🚀 GETTING STARTED (15 MINUTES)
─────────────────────────────────────────────────────────────────────────────

Step 1: Firebase Setup (5 min)
  1. Go to https://console.firebase.google.com
  2. Create project "QueueLess Lite"
  3. Copy Firebase config to .env file
  4. Enable Authentication (Email + Google)
  5. Create Firestore Database (Test Mode)
  6. Copy security rules to Firestore

Step 2: Install & Run (10 min)
  npm install
  npm start
  
  Opens at http://localhost:3000

Step 3: Test
  1. Create business account
  2. Create waitlist
  3. Add customers
  4. Test QR code
  5. Join as customer
  6. Watch real-time updates!
