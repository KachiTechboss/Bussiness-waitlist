## Quick Troubleshooting

### "npm install fails"
- Make sure you have Node.js installed
- Try: `npm cache clean --force` then `npm install` again

### "npm start doesn't work"
- Check that `.env` file exists with Firebase keys
- Restart the server: Ctrl+C, then `npm start`

### "Firebase errors in console"
- Verify `.env` keys match Firebase project
- Check Firestore Rules in Firebase console (copy from FIRESTORE_RULES.js)

### "Queue not updating in real-time"
- Open DevTools (F12) → Console
- Check for Firestore permission errors
- Verify Rules are published in Firebase
